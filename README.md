# Modelagem-3D
Modelagem 3D

Bem-vindo ao meu repositório de modelagem 3D. Aqui compartilho projetos desenvolvidos em modelagem, texturização e criação de ambientes e objetos digitais, utilizando criatividade, atenção aos detalhes e foco em aprendizado constante.

Tenho interesse em desenvolver modelos com boa organização, estética visual e otimização, explorando tanto projetos autorais quanto estudos voltados para jogos, animação e visualização 3D. Este repositório reúne arquivos, texturas e experimentos que representam minha evolução na área.

Objetivo

Meu objetivo é continuar evoluindo como artista 3D e desenvolvedor criativo, aprimorando técnicas de modelagem, texturização e criação de projetos cada vez mais detalhados e profissionais.

Sinta-se à vontade para explorar os arquivos e acompanhar minha evolução.
